**The cognitive substrate beneath the agentic mesh.**
Mesh intelligence on an open protocol. Pioneered by [SYM.BOT](https://sym.bot).

This repository is the published static site for **[meshcognition.org](https://meshcognition.org)**, served by GitHub Pages from `main`.

## What is Mesh Cognition?

Mesh Cognition is a mesh-intelligence architectural pattern in which specialised agents share semantically-typed observations through a wire protocol with per-field admission, while each agent maintains sovereign learned state that is per-node and not merged across nodes.

Many independent cognitions — humans, models, processes — sharing partial state (focus, mood, intent, commitment) over a protocol. Each receiver decides locally what to admit, remix, and act on. Not a hive mind. Not federation. Closer to how a research lab thinks: people overhear, take what's relevant, and the group converges without anyone in charge.

MMP carries the thoughts. SVAF decides admission. Content-hash lineage keeps the trail reconstructible.
