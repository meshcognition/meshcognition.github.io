FIG.09 · IMPLEMENTATIONS

Reference implementations & deployments.

Mesh Cognition is the architectural pattern for mesh intelligence, formalized as an open standard (MMP + SVAF, published CC BY 4.0), with one reference runtime, built and maintained by SYM.BOT. Class 1 (§17.1) is the documented third-party emitter surface, with published test vectors; SYM is the maintained open reference implementation of Class 2 cognition-node behavior. Third-party emitters and integrations are welcomed.

The standard & the reference runtime (SYM)
