# meshcognition.github.io

GitHub Pages deploy target for **[meshcognition.org](https://meshcognition.org)** — the open home of **Mesh Cognition** and the **Mesh Memory Protocol (MMP)**.

Mesh Cognition is a distributed-intelligence architectural pattern with per-user sovereignty, formalized as an open protocol. Pioneered by [SYM.BOT](https://sym.bot).

- **Spec:** the canonical **MMP v1.0** specification lives at **<https://meshcognition.org/spec/mmp>** (CC-BY-4.0).
- **Research:** <https://meshcognition.org/research> — the MMP, SVAF, and MeloTune papers.

This repository holds the built static site, published via GitHub Pages. It is generated from a private Astro source.
