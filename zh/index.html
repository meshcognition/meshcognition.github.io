FIG.02 · 定义

什么是 Mesh Cognition?

Mesh Cognition 是一种面向网格智能的架构范式:每个专业智能体对外发射其自身认知状态的语义类型化投影—从不传输状态本身;每个接收方按字段准入(per-field admission)、以自己的条件将其纳入自己的主权存储。学习状态始终留在节点本地,永不跨节点合并。

多个独立认知主体—人类、模型、流程—各自通过协议发出自身本地状态的类型化投影(例如:注意力焦点、情绪倾向、意图、承诺)。每个接收方在本地自主决定:接纳哪些信息、如何重组、采取何种行动。

没有合并状态。没有协调权威。更接近科研团队的思考方式:成员选择性接收相关信息,群体在无人指挥下收敛。

MMP 承载类型化的认知记忆块(Cognitive Memory Blocks)。SVAF 决定字段级准入。内容哈希溯源确保认知链路可重建。

六项特性,将该范式与中心编排的多智能体系统区分开来。

01

按字段准入

每个接收方逐字段准入或拒绝传入观测,而非整条消息全收/全拒—各自依据自身的准入策略评估每个类型化语义字段。该机制形式化定义为符号-向量注意力融合(Symbolic-Vector Attention Fusion, SVAF)—定义详见 MMP §9。

02

类型化投影(CAT7)

MMP 在认知节点之间承载的,是认知状态的语义类型化投影:一个 CAT7 认知记忆块(Cognitive Memory Block),而非自由格式消息或工具调用。其字段来自 CAT7 词汇表(注意力焦点、问题、意图、动机、承诺、视角、情绪),观测以类型化形式到达—按字段准入因此有了可判定的对象。

03

重组与溯源

接收方对所准入的内容进行重组,而非原样转发—因此不存在需要协调的共享全局状态。派生块通过父代/祖先引用保留至其源观测的内容哈希溯源,使其所引用的溯源关系可跨主权存储重建:其溯源链标识所引用的源观测。

04

节点主权状态

架构设计层面确保跨节点状态零合并—这并非策略选择,而是协议规范的内生属性。每个节点具有一个主权状态边界:节点如有习得状态,该状态始终留在本地,协议不跨节点合并。节点可以是一个用户、一个服务、一个团队或一个组织。

05

无需云端

协议从不要求习得的节点状态跨越网络。开放协议实现互操作,而规范不要求云端或中央服务器。协议规范本身不要求任何云端组件。

06

自我选择,而非指派

许多多智能体框架使用编排器或预配置图来选择由哪个智能体行动。该范式不要求中央指派者:每个节点在本地决定是否准入输入、据此行动并贡献观测。因此,参与是自我选择的—协调是众多接收方本地决策的涌现产物,而非指挥者的输出。

核心摘要

六项特性,一个架构范式。

FIG.03 · 动机

为何重要?

生物智能是其结构上的先例。人脑中没有任何单个神经元充当系统级的控制器。其数百亿神经元各自接收大量输入—通常发生在效应强弱不一的突触上—经由不断变化的膜与生化动力学加以整合,再通过动作电位与突触释放向下游传递信号。没有单个神经元主宰全局;感知与思维,依赖于分布在相互作用的神经环路中的活动—尽管这些过程如何产生认知,仍是一个悬而未决的科学问题。Mesh Cognition 把有限的局部单元、逐连接的影响、部分性的信号传递,以及没有单一控制器,作为智能体间集体智能的结构启发—这是结构启发,并非生物学等同。在这一架构中,认知节点是主权单元:一个立于自身准入边界之后的参与者。

这一思想有久远的谱系。心理学、认知科学与哲学中,有若干关于分布式认知的重要论述:明斯基的「心智社会」—由简单、本身并无心智的过程组合出智能活动;跨越人与人造物的分布式认知,以及「延展心智」论证(某些外部资源构成认知过程的一部分);关于交互记忆的研究(群体得以组织起对分散于各成员之间的知识的调用)。在这些各不相同的传统之间,反复出现的主题是:有限的、处境各异的贡献者之间的协调,而没有谁持有全部。

而许多智能体系统采用了相反的模式。单一模型、单一上下文、单一视角—智能体间的协调还要经由一个指挥者中转。一些复杂问题可受益于专业智能体并行思考、在彼此的观测之上继续推进;对这些问题而言,模型能力并非唯一约束—参与者之间的协同带宽同样关键。

中心化协调无法支撑自主扩展。若每个智能体均需向中央控制器请示,控制器即成为系统天花板。接收方自主准入机制避免以中央准入控制器成为扩展瓶颈,同时避免重新引入主控节点。

主权架构赋能机构级应用。机构需要对习得状态进行本地控制,并建立可审计的交换边界。它们可向协议发射类型化投影—习得状态始终留在本地,所引用的溯源关系可重建。

集体认知在模型要求之上,还增加了基础设施要求。

FIG.04 · 定位

定位。

定位声明 Mesh Cognition 不是产品,不是编排器,也不是网络原语。它是面向网格智能、以节点主权为核心、形式化为开放标准的架构范式:节点发射自身认知状态的类型化投影,每个接收方自主决定准入什么、依据什么行动。
